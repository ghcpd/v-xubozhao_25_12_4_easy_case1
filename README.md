# Monthly Sales Charts

This repository contains `monthl_sales.json` and a small script `plot_sales.py` that generates two charts:

- `line_chart.png` — line chart of monthly sales
- `bar_chart.png` — bar chart of monthly sales

Requirements
- Python 3.8+
- matplotlib

Install dependencies (PowerShell):

```pwsh
python -m pip install --upgrade pip
pip install matplotlib
```

Run the script:

```pwsh
python plot_sales.py
```

The images will be saved in the same folder as `plot_sales.py`.
